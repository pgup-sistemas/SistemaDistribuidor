Configuração de Ambiente

Configure as seguintes variáveis de ambiente no seu servidor:

Arquivo .env
# Integração NF-e
NFE_ENVIRONMENT=homologation  # ou production
NFE_API_PROVIDER=sefaz        # sefaz, focusnfe
NFE_CERT_PATH=/path/to/cert.pfx
NFE_CERT_PASSWORD=your_password
NFE_DEFAULT_MARKUP=1.3        # 30% markup
NFE_DEFAULT_MIN_STOCK=5
Para SEFAZ (Gratuito):
  • Certificado Digital A1/A3
  • Complexidade alta de implementação
  • Manutenção de certificados
  • Conformidade total
Para Provedores (Pago):
  • API pronta para uso

Próximos Passos para Ativação
1. Escolher Provedor

Contrate um provedor de API NF-e ou prepare certificados SEFAZ.

2. Configurar Ambiente

Defina as variáveis de ambiente no servidor de produção.

3. Testar Integração

Use o botão "Testar Conexão" para validar a configuração.

4. Ativar em Produção

Mude NFE_ENVIRONMENT para 'production'.

5. Monitorar

Acompanhe logs e use dados reais de NF-e.

6. Suporte

Entre em contato conosco para assistência técnica.

Dica Importante

Comece com um provedor pago para validar o fluxo, depois migre para SEFAZ direto se necessário. A diferença de custo (R$ 100-200/mês) é compensada pela agilidade e suporte técnico.
