Como Usar
Consulta por Chave:
  1. Obtenha a chave de acesso da NF-e (44 dígitos)
  2. Selecione o fornecedor correspondente
  3. Clique em "Consultar NF-e"
  4. Revise os dados e clique em "Importar Produtos"
Upload de XML:
  1. Baixe o XML da NF-e do SEFAZ
  2. Selecione o fornecedor
  3. Faça upload do arquivo XML
  4. Os produtos serão importados automaticamente
Nota: Atualmente o sistema trabalha com dados simulados. Para integração real, configure um provedor de API NF-e nas configurações.
